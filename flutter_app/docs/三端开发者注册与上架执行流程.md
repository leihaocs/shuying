## 1. 全景：三条线并行，最后一个汇合点

```
线 A · 资质       软著/电子版权 ────────────────┐
                  域名+云服务器 → 备案 ─────────┤
                                                ├──► D-Day：三端提交上架
线 B · 账号       苹果 / 华为 / 安卓渠道注册 ───┤
                                                │
线 C · 工程素材   平台工程+签名+图标+截图+隐私页 ┘
                   （Windows 可做安卓；iOS/鸿蒙需 macOS）
```

**关键判断**：线 B 是最容易被低估的一条。苹果账号从注册到能用通常 1~5 天（可能被要求补材料），
国内安卓各平台实名认证 1~3 天，华为 + 鸿蒙要在一个账号下开两个独立应用条目。
**所以账号注册要在 D0 就和软著一起启动，别等资质下来再注册。**

### 建议节奏

| 时间 | 动作 |
|---|---|
| D0 | ① 开软著/电子版权申请 ② **注册 Apple Developer**（实名验证有等待期）③ 注册华为开发者联盟 ④ 买域名+轻量服务器 |
| D0~D1 | 写并托管隐私政策页；开始域名实名认证（3~5 天） |
| D1~D3 | 注册小米/OPPO/vivo/荣耀/应用宝；准备图标与截图 |
| D3 | 平台工程生成 + 三端签名配置 + 三端 release 包跑通真机 |
| D3~D20 | 网站备案 → App 备案（三端特征信息一次填齐） |
| D5 或 D60 | 拿到软著/电子版权（取决于走哪条通道） |
| 材料齐 | 依次提交：华为 AGC（鸿蒙）→ 各安卓市场 → App Store |

## 2. 线 B：开发者账号注册（本文重点）

### 2.1 Apple Developer Program（iOS，唯一收费项）

#### 前置条件（缺一项就卡住）

| 条件 | 说明 |
|---|---|
| Apple ID | 建议**新注册一个专用 Apple ID**，不要用个人日常号（后续要给客户/合作者开权限，也方便转让） |
| 双重认证 | 必须开启，否则无法注册 |
| 身份验证 | **中国大陆的账户持有人必须做身份验证**，用身份证 + 人脸，在 Apple Developer App 里完成 |
| 支付方式 | 支持信用卡；中国区年费 **99 美元 ≈ 688 元人民币**（按当地货币结算） |
| 若用组织账号 | 额外需要 **D-U-N-S 邓白氏编码**（免费申请，通常 1~5 个工作日；无编码会被直接驳回） |

#### 个人账号 vs 组织账号怎么选

| | 个人（Individual） | 组织（Organization / Company） |
|---|---|---|
| 显示在商店 | 开发者名称 = **你的真实姓名拼音** | 开发者名称 = **公司名** |
| 需要的材料 | 身份证 + 人脸 | 营业执照 + D-U-N-S 编码 + 公司网站/邮箱验证 |
| 费用 | 688 元/年 | 99 美元/年（约 688 元） |
| 审核时长 | 通常 1~3 天 | 3~10 天，被要求补材料更久 |
| 适合谁 | 先跑通流程、个人作品 | 有营业执照、要做长期品牌 |

> **建议**：如果「书影温故」将来要作为品牌长期运营、或有公司主体，直接上组织账号，省得以后迁移（App 转让很麻烦）。
> 如果只是个人练手并希望尽快上架，个人账号最快。

#### 注册 7 步

1. 注册 Apple ID → 开启双重认证
2. iPhone/iPad 上安装 **Apple Developer** App（注册用 App 走，比网页版顺畅）
3. App 内「Account」→ 登录 → 「Enroll」
4. 选 **Individual**（个人）或 **Organization**（组织）
5. 填写真实姓名（**中文名对应的拼音必须与身份证一致**）、地址、电话
6. 完成身份验证（个人：身份证正反面 + 人脸；组织：公司信息 + D-U-N-S）
7. 同意《Apple Developer Program 许可协议》→ 支付 → 等待审核邮件（1~3 天）

> 网页端也可走 https://developer.apple.com/programs/enroll/ ，但中国大陆用户走 App 的实名验证流程更顺。

#### 注册通过后立刻做的 6 件事

1. **App Store Connect**（https://appstoreconnect.apple.com）→ 我的 App → 「+」新建 App
   - 平台：iOS
   - 名称：`书影温故`
   - 主要语言：简体中文
   - Bundle ID：选 `com.bookmovie.revisit.app`（**需要先在开发者后台 Identifiers 里创建这个 App ID**）
   - SKU：自定义唯一串，如 `shuyingwengu001`（用户看不到）
2. 开发者后台 → Certificates, Identifiers & Profiles → **Identifiers** 新建 App ID（Explicit，填 `com.bookmovie.revisit.app`）
3. 后台 → **Users and Access** → 把参与上架的人加成 `App Manager`（不要共用主账号）
4. App Store Connect → **协议、税务和银行业务**：免费 App 也要签「Free Apps 协议」，否则 App 无法上架
5. 生成 iOS 发布证书 + 描述文件（见 4.3 节），或用 Xcode 自动签名
6. 准备 App 隐私「营养标签」：本项目选择「**不收集任何数据**」

#### 常见卡点

| 现象 | 原因 / 处理 |
|---|---|
| Enroll 页面一直转圈 / 无法支付 | 换 Apple Developer App；确认 Apple ID 的双重认证已开启 |
| 提示需要身份验证 | 中国大陆账户持有人在 App 内做身份证 + 人脸验证 |
| 组织账号被驳回 | 缺 D-U-N-S 编码，或公司名/地址与邓白氏记录不一致 |
| 开发者名称想改成公司名 | 个人账号不能改。要么重新注册组织账号，要么走账号转让 |
| 上架中国区被要求填 ICP 备案号 | 见 3.2 节，先在 App Store Connect「App 信息」里填备案号 |

### 2.2 华为开发者联盟（同时覆盖 HarmonyOS 应用市场 + 华为应用市场）

**核心认知：同一个华为开发者账号，在 AppGallery Connect（AGC）里是「两个独立应用条目」**——
一个是 HarmonyOS 应用，一个是 Android（APK）应用。资料要**分别填、分别过审**，但备案号可以共用。

#### 注册 5 步

1. 进 https://developer.huawei.com/consumer/cn/ → 注册（手机号/邮箱）
2. **实名认证**——二选一：

| 类型 | 材料 | 耗时 |
|---|---|---|
| 个人开发者 | 身份证 + 人脸识别 | 通常当天~1 天 |
| 企业开发者 | 营业执照、法人信息、**对公账户打款验证**（华为向你账户打一笔随机金额，回填金额确认） | 1~3 天 |

3. 登录 AGC：https://developer.huawei.com/consumer/cn/service/josp/agc/index.html
4. 「我的项目」→ 新建项目 → 「我的应用」→ **新建应用**，平台选 **HarmonyOS**
   （同一项目下再建一个 **Android** 应用条目，用于华为应用市场）
5. 填应用包名 `com.bookmovie.revisit.app`（创建后包名不可改）

#### 鸿蒙上架必须齐的 5 样（缺一样直接驳回）

| 项 | 说明 |
|---|---|
| **APP 备案（华为叫「APP 核准」）** | 工信部备案号必须有效，且**应用名称与包名要与备案信息完全一致** |
| **软著 或 电子版权认证证书** | 二者有其一即可（见 3.1 节，鸿蒙有更快的电子版权通道） |
| **隐私政策链接** | 必须 HTTPS、公网可访问 |
| **已签名软件包** | `.app`（APP Pack）；签名用 AGC 生成的 `.p12` + `.p7b` Profile（见 4.3 节） |
| **应用信息** | 名称、图标（216×216）、一句话简介、应用介绍、**3~5 张竖版截图**、分类标签、内容分级、语言 |

#### 个人开发者注意

- 鸿蒙应用个人开发者可以上架，但**部分品类受限**（如金融、医疗、新闻资讯等需企业资质）。
  「书影温故」属于工具/效率类，个人可上架。
- 华为应用市场（Android 条目）对个人开发者的审核更严，部分品类要求「开发者承诺函」。
- 如果你的主体是公司，**统一用企业认证**，三端所有市场都走企业身份，最省事。

### 2.3 国内安卓渠道（5 家主力，全部免费）

| 平台 | 注册入口 | 认证方式 | 备注 |
|---|---|---|---|
| **华为应用市场** | developer.huawei.com | 同上（复用华为账号） | 与鸿蒙条目分开建 |
| **小米应用商店** | dev.mi.com | 个人：身份证人脸；企业：营业执照 + 对公打款 | 个人开发者需额外提交承诺函 |
| **OPPO 开放平台** | open.oppomobile.com | 个人/企业实名 | 个人开发者账号注册需「开发者认证」 |
| **vivo 开放平台** | dev.vivo.com.cn | 个人/企业实名 | 账号须绑邮箱或手机号，**别用私人邮箱** |
| **荣耀开发者** | developer.honor.com | 个人/企业实名 | 与华为体系独立，需单独注册 |
| **应用宝（腾讯）** | open.qq.com | 个人/企业实名 | 审核最严，通常要求企业主体 + 软著 |
| 豌豆荚 / 百度手机助手 | 各自平台 | — | 量级已小，可按需补 |

**实操建议**：

1. **一次性把 5 家账号都注册掉**，认证审核是并行的，不要串行等。
2. 用**专用邮箱**注册（如 `dev@yourdomain.com`），避免个人邮箱离职/遗失导致账号拿不回来。
3. 每家的上架表单高度雷同，**先把资料整理成一个文件夹**，逐家复制：
   - APK（`flutter build apk --release --split-per-abi` 的 `arm64-v8a` 包）
   - 512×512 图标 PNG
   - 3~5 张 1080×1920 竖版截图
   - 隐私政策 URL
   - 软著证书扫描件
   - ICP 备案号（`粤ICP备xxxxxxxx号-1A`）
   - 应用简介 / 详细介绍 / 关键词 / 更新日志
4. 各家表单域名不同但要求的**包名必填 `com.bookmovie.revisit.app`**，务必逐家核对。

> **关于个人开发者的现实情况（2026）**：华为、小米、OPPO、vivo、应用宝**都把软著（或电子版权证书）
> 作为硬门槛**，无软著基本无法过审。个人身份本身不是障碍，缺资质才是。

## 3. 线 A：资质（详细步骤见 `上架前置资质与备案指引.md`，这里只补关键决策）

### 3.1 软著：两条通道，先选一条

| 通道 | 周期 | 费用 | 适用 |
|---|---|---|---|
| **中国版权保护中心**（传统软著） | 官方 30~60 工作日；加急 1~3 工作日 | 官费 0 元；加急代办 300~1500 元 | 时间充裕，或需要「正牌软著」用于多平台长期使用 |
| **易版权平台 · 电子版权认证（鸿蒙版）** | **10~15 个工作日** | 常有免费额度（需华为账号登录、符合活动条件） | 想尽快过华为/鸿蒙审核 |

**关键事实**：华为明确「**软著或电子版权认证证书，二者有其一即可**」。
国内各安卓市场也逐步接受《APP 电子版权认证证书》。
所以：**想快就走电子版权通道，想稳就走传统软著 + 加急。**

- 软著名称建议：`书影温故阅读观影记录软件` V1.0，简称 `书影温故`
- 源码文档、说明书排版要求见既有文档 1.4 / 1.5 节（页眉含名称+版本号、每页 ≥ 50 行、有页码）
- 逻辑红线：**开发完成日期 ≤ 首次发表日期**

### 3.2 APP 备案（工信部，三端共用一次）

- 依据《工业和信息化部关于开展移动互联网应用程序备案工作的通知》，**上线前必须完成备案**。
- **三端同名（都叫「书影温故」）→ 只备案一次**，发一个 `-1A` 结尾的备案号，三端都能用。
- 前提：你名下要有**域名 + 云服务器实例**（剩余时长 > 3 个月），用它的「备案服务码」提交。
- 提交时**一次把三端特征信息填齐**：

| 平台 | 标识符 | 指纹 |
|---|---|---|
| Android | 包名 `com.bookmovie.revisit.app` | 证书 **MD5** |
| iOS | Bundle ID `com.bookmovie.revisit.app` | 证书 **SHA-1** |
| HarmonyOS | 包名 `com.bookmovie.revisit.app` | 证书 **MD5 指纹** |

- **提交后 24 小时内必须回复工信部核验短信**，否则订单被驳回。
- iOS 发布证书续期后若公钥 / SHA-1 变化，**必须走「变更备案」**更新特征信息。

### 3.3 隐私政策

- 公网可访问的 HTTPS 链接（GitHub Pages / Gitee Pages / Cloudflare Pages 都免费）。
- **App 内必须有**：首次启动同意弹窗 + 设置页常驻入口。
  > 本项目**已完成**：`lib/pages/privacy_consent_gate.dart`（首启弹窗）
  > 与 `lib/pages/settings_page.dart` + `lib/pages/privacy_policy_page.dart`（设置页入口 + 撤回同意）。
- 本项目纯本地、不联网、无 SDK，隐私政策文本可以写得很短，是所有审核里最好过的一类。
  全文可直接取自既有文档 3.3 节（名称已是正式名，填上真实邮箱与日期即可）。
- 若隐私政策页做成了公网网页，**文本内容必须与 App 内文本一致**（审核会逐条比对）。

## 4. 线 C：工程侧三端落地

### 4.1 生成平台工程（按你的操作系统分）

当前 `flutter_app/` 下**还没有** `android/`、`ios/`、`ohos/` 目录，需要先生成。

| 你的机器 | 能做什么 |
|---|---|
| **Windows**（你现在这台） | 只能生成并构建 **Android**；iOS 与鸿蒙**做不了** |
| **macOS** | iOS + Android 全流程；鸿蒙建议在 macOS + DevEco Studio 完成 |

**iOS 必须在 macOS 上出包**（Xcode 只跑 macOS）。
**鸿蒙出包**需要 DevEco Studio + OpenHarmony 分支的 Flutter SDK（见 README 第五节），Windows 版 DevEco 可以开发和调试，但**正式签名包与 AGC 上传建议在 macOS 上做**，避免签名链差异。

生成命令（`tool/bootstrap.sh` 已按真实包名改好，见 4.2）：

```bash
# macOS / Linux
cd flutter_app
chmod +x tool/bootstrap.sh
./tool/bootstrap.sh com.bookmovie.revisit.app
```

```powershell
# Windows PowerShell（只生成 android）
cd d:\Codes\APPdev\flutter_app
flutter create --platforms=android --org com.bookmovie.revisit --project-name app .
```

### 4.2 三端标识符与显示名对照表（生成后逐一核对）

| 平台 | 标识符位置 | 应填 | 显示名位置 | 应填 |
|---|---|---|---|---|
| Android | `android/app/build.gradle.kts` 的 `applicationId` | `com.bookmovie.revisit.app` | `android/app/src/main/AndroidManifest.xml` 的 `android:label` | `书影温故` |
| iOS | Xcode → Runner → Signing 的 `PRODUCT_BUNDLE_IDENTIFIER` | `com.bookmovie.revisit.app` | `ios/Runner/Info.plist` 的 `CFBundleDisplayName` | `书影温故` |
| HarmonyOS | `ohos/AppScope/app.json5` 的 `bundleName` | `com.bookmovie.revisit.app` | `ohos/entry/src/main/resources/base/element/string.json` 的 `app_name` | `书影温故` |

同时补一个中文名易读性细节：iOS 显示名建议 ≤ 6 个汉字，`书影温故` 4 字完全 OK，无需缩写。

### 4.3 三端签名配置

#### Android（keystore，**丢了就永远无法更新**）

```bash
keytool -genkey -v -keystore ~/keys/shuyingwengu-release.jks \
  -keyalg RSA -keysize 2048 -validity 10000 -alias shuyingwengu
```

- 新建 `android/key.properties`（已在 `.gitignore` 里，不要提交）：

```properties
storePassword=你的store密码
keyPassword=你的key密码
keyAlias=shuyingwengu
storeFile=/Users/你的用户名/keys/shuyingwengu-release.jks
```

- 在 `android/app/build.gradle.kts` 里配置 `signingConfigs.release` 并让 `buildTypes.release` 使用它（完整片段见 README 第四节）。
- **备份策略**：`.jks` + 密码 + alias 三样一起，**至少两份异地备份**（网盘 + U 盘）。
- 建议**不要**启用 Google Play App Signing 之外的上传密钥托管；国内各市场直接用同一个 `.jks`。

#### iOS（证书 + 描述文件）

1. 开发者后台 → Certificates → 新建 **Apple Distribution** 证书（需先在 Mac 上生成 CSR）
2. Identifiers → 创建 `com.bookmovie.revisit.app`
3. Profiles → 新建 **App Store Connect** 分发描述文件，绑定上面的证书与 App ID
4. Xcode：`open ios/Runner.xcworkspace` → Runner Target → Signing & Capabilities →
   勾选 `Automatically manage signing`，Team 选账号，Bundle Identifier 填 `com.bookmovie.revisit.app`
5. 需要手工签名时，把 `.p12`（证书+私钥导出）与 `.mobileprovision` 装到构建机上

> 有效期：发布证书通常 3 年、分发描述文件 1 年（以后台显示为准）。
> **续期后如果公钥/SHA-1 变了，记得走「变更备案」**，否则会「备案信息与实际证书不一致」。

#### HarmonyOS（`.p12` + `.p7b`）

全部在 AGC 生成，比 Android/iOS 简单：

1. AGC → 「证书、APP ID 和 Profile」→ 新建 **发布证书**（可先在本地用 DevEco 或命令行生成 `.csr`）
2. 上传 CSR → 下载 `.cer`；同时生成 `.p12` 密钥库（**密钥库口令必须记牢，丢失无法更新**）
3. 创建 **Profile**（发布类型）→ 下载 `.p7b`
4. 在 DevEco Studio：`File → Project Structure → Signing Configs`
   填入 `.p12` / `.cer` / `.p7b`，或勾选「自动生成签名」并登录华为账号
5. 建议**开启 AGC 的自动签名（Automatically manage signing）**，续期时省事

> 备案需要的鸿蒙侧「公钥 + 证书 MD5 指纹」：下载开发者证书 → 用文本编辑器打开 →
> **删除证书链部分只保留最后一段** → 保存 → 查看「详细信息 → 公钥」与「详细信息 → 指纹」。

## 5. 提交上架（三端各自的入口与顺序）

### 5.1 App Store Connect

1. 用 Xcode 或 `flutter build ipa` 上传构建版本（也可用 Transporter）
2. 填 App 信息：名称 `书影温故`、副标题、类别（**图书 或 效率**）、年龄分级、隐私政策 URL
3. **中国区必须填 ICP 备案号**（App 信息 → 中国大陆地区）
4. 上传截图、写简介与关键词、填审核备注（说明「无需登录，无账号体系」）
5. App 隐私：选「不收集数据」
6. 先走 **TestFlight** 内测（自己 + 1~2 人），确认无误再「提交以供审核」
7. 首次审核通常 1~3 天；被驳回会说明理由，改完重新提交即可（不额外收费）

> 本项目无账号体系，因此**不需要**「账号删除入口」；但如果将来加了登录，苹果强制要求提供 App 内注销功能。

### 5.2 华为 AGC（鸿蒙条目 + 安卓条目）

1. AGC → 我的应用 → 选对应条目 → 「版本信息」
2. 上传 `.app`（鸿蒙）或 APK（安卓）
3. 填版权信息：上传**软著或电子版权证书**
4. 填隐私政策链接、APP 备案（核准）信息
5. 填应用信息（简介/截图/分类/分级）→ 提交审核
6. 审核一般 1~3 个工作日；鸿蒙应用可用「互动中心」申请加急

### 5.3 国内安卓各市场

逐家上传 APK + 资料。**先提交最严格的应用宝 / 小米**，如果能过，其余基本都能过；
若被驳回，问题多半是「软著 / 备案号 / 隐私政策」三件套之一，改一处可复用其它家。

## 9. 一页速查：最常见的 8 个驳回原因

| 现象 | 原因 | 解决 |
|---|---|---|
| 各市场驳回：缺资质 | 没有软著/电子版权 | 走 3.1 节两条通道之一 |
| 各市场驳回：缺备案 | 没有 `-1A` 备案号 | 先把备案办下来，没有捷径 |
| 备案驳回 | 没在 24 小时内回工信部短信 | 提交后盯手机，收到 12381 立刻回复 |
| 备案驳回 | App 名称与软著名称差异大 | 统一为「书影温故」 |
| 备案卡住 | 没有云服务器实例 / 剩余时长不足 3 个月 | 先续费到 3 个月以上 |
| 审核驳回 | App 内没有隐私政策入口 | 本项目已做（首启弹窗 + 设置页入口），确认文案与公网版一致 |
| 审核驳回 | 权限列表有 INTERNET 却声称不联网 | 检查 `main/AndroidManifest.xml` |
| 华为找不到鸿蒙应用 | 安卓与鸿蒙是两个独立条目 | 在 AGC 分别新建、分别提交 |
