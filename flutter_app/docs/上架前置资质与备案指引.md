## 0. 全局：先搞清三件事的关系和时间线

### 0.1 三件事不是串行的，但有个"隐形依赖"

```
软著登记  ────────────────┐
（30~60 工作日，最慢）      │
                          ├──► 应用市场提交上架
域名 + 云服务器 ─► 网站备案 ─► App备案 ─┘
（1~3 天买好）   （20 工作日）
                          ▲
隐私政策网页  ─────────────┘
（1 天搞定）
```

- **软著**和**备案**之间**没有依赖关系**，可以同时办，但**上架时两样都必须有**，所以两条线要并行开工。
- **备案有个前提**：必须有一个"接入服务商"（即你名下的域名 + 云服务器）。这一步买完当天就能用，所以别拖到最后。
- **隐私政策**最便宜最简单，但**苹果和所有安卓市场都会卡它**，建议和软著同一天开始。

### 0.2 一张表看懂成本与耗时

| 事项 | 谁办 | 耗时 | 费用 | 能并行 |
|---|---|---|---|---|
| 软件著作权 | 版权保护中心 / 代办 | 官方 30~60 工作日；加急 1~3 工作日 | 官费 **0 元**（2017 年起停征）；代办 0~800 元 | ✅ |
| 域名 | 阿里云 / 腾讯云 | 即时 | 约 10~40 元/年 | ✅ |
| 云服务器（备案用） | 阿里云 / 腾讯云 | 即时 | 约 60~120 元/年（轻量应用服务器首年优惠价） | ✅ |
| 网站备案 | 云厂商代提交 | 1~20 工作日 | 0 元 | ✅ |
| App 备案 | 云厂商代提交 | 1~20 工作日 | 0 元 | ✅ |
| 隐私政策页面 | 你自己 | 1 小时 | 0 元（GitHub Pages 免费） | ✅ |
| 应用商店开发者账号 | 各商店 | 1~3 工作日实名 | 国内商店**免费**；Apple 688 元/年 | ✅ |

**总现金支出（面向国内三端）**：约 **100~200 元/年**（域名 + 服务器）+ 可选的软著代办费 + Apple 的 688 元/年。
**最短上线时间**：约 **2~4 周**（走软著加急 + 备案顺利的情况下）。

### 0.3 一条铁律：三个名字必须一致

**软著名称 = App 备案名称 = 应用商店名称**，三者务必保持一致或能明显对应。

例如统一成：

| 位置 | 填什么 |
|---|---|
| 软著 | `书影温故阅读观影记录软件` V1.0，简称 `书影温故` |
| App 备案 | `书影温故`（App 名称）+ 备注里关联软著 |
| 应用商店 | `书影温故` |
| App 安装后桌面显示 | `书影温故` |
| App 内的文案 | `书影温故`（已于 2026-09-23 全量统一，Android 显示名同步设置） |
| 英文名（海外市场） | `Reel & Read` |

一旦三者差异过大（比如软著叫"XX管理系统"、App 叫"书影温故"），市场会要求你补交"软著与 App 为同一应用"的说明材料，来回折腾一两周。

### 0.4 建议的执行节奏

| 时间 | 动作 |
|---|---|
| D0 | 买域名 + 轻量服务器；同时把隐私政策写出来托管好 |
| D1 | 提交软著申请（决定走加急就先找代办）；发起网站备案 |
| D3~D20 | 网站备案下来 → 立刻发起 App 备案；同时准备图标/截图 |
| D3~D60 | 等软著（走加急的话 D3~D5 就下证） |
| 材料齐了 | 注册各商店开发者账号 → 提交上架 |

## 1. 软件著作权登记（软著）

### 1.1 为什么必须

国内安卓市场（华为/小米/OPPO/vivo/荣耀/应用宝）几乎是**强制**要求提供软著证书。
严格来说部分市场接受"App 备案 + 承诺函"替代，但实际上**没有软著大概率被驳回**，别赌。

App Store 不强制软著，但中国区需要备案号。

### 1.2 官方办理 vs 代办：怎么选

| | 官方自办 | 找代办 |
|---|---|---|
| 费用 | **0 元**（官费已停征） | 0~400 元（普通）；300~1500 元（加急） |
| 耗时 | 30~60 个工作日 | 普通同上；加急 **1~3 个工作日**出证 |
| 材料 | 自己排版（最容易出错） | 代办帮你格式化，补正风险低 |
| 适合谁 | 不着急上线、愿意自己抠格式 | 想尽快上线、不想反复补正 |

**我的建议**：既然你要三端上线，时间成本远高于几百块，**直接走加急代办**。但注意挑选正规渠道，
可以直接在版权保护中心官网自办，或选口碑好的代理；不要买"包授权"的野鸡服务。

> 官方办理完全免费，且**电子证书在版权保护中心官网可自行下载**，很多市场接受电子证书打印件/截图。

### 1.3 材料四件套

1. **《计算机软件著作权登记申请表》** —— 在中国版权保护中心官网在线填写
2. **身份证明文件**
   - 个人：身份证正反面扫描件（清晰、完整、在有效期内）
   - 公司：营业执照副本扫描件
3. **源代码文档**
4. **软件说明书**（用户操作说明书）

### 1.4 源代码文档：格式硬要求（最容易踩坑）

| 要求 | 具体规定 |
|---|---|
| 文件格式 | Word（.docx）或 PDF |
| 页眉 | **必须**包含「软件名称 + 版本号」，如 `书影温故阅读记录软件 V1.0` |
| 页码 | 必须有页码 |
| 每页行数 | **每页不少于 50 行代码** |
| 提交范围 | **前 30 页 + 后 30 页，共 60 页**；代码总行数不足 60 页则提交全部 |
| 内容要求 | 开头和结尾的代码要能体现独创性，不能是空行、注释、开源库代码 |

**绝对不要**直接提交项目压缩包或整个文件夹。

#### 本项目怎么生成（Dart 代码，lib/ 下 21 个文件）

先统计行数，确认够不够 60 页（60 × 50 = 3000 行）：

```bash
cd flutter_app
find lib -name "*.dart" -exec wc -l {} + | tail -1
```

如果够 3000 行，正常按"前 30 页 + 后 30 页"提交。
如果不够（本项目大约 4000+ 行，通常够），就全部提交。

**合并成一个文本文件**（任选其一）：

```bash
# macOS / Linux
cd flutter_app
mkdir -p docs/sourcecode
find lib -name "*.dart" | sort | xargs -I{} sh -c 'echo "// ===== {} ====="; cat {}; echo' > docs/sourcecode/all_dart_code.txt
wc -l docs/sourcecode/all_dart_code.txt
```

```powershell
# Windows PowerShell
cd d:\Codes\APPdev\flutter_app
Get-ChildItem -Recurse -Filter *.dart lib | Sort-Object FullName | ForEach-Object {
  "// ===== $($_.FullName) ====="
  Get-Content $_.FullName
} | Set-Content -Encoding UTF8 docs\sourcecode\all_dart_code.txt
(Get-Content docs\sourcecode\all_dart_code.txt).Count
```

**排版成 Word / PDF**：不要手工复制粘贴，用工具自动加页眉页码，推荐两个免费开源方案：

- `SourceCodeDocxGenerator`（GitHub 开源，本地运行）—— https://github.com/CharlieJiang/SourceCodeDocxGenerator
- 阿里云开发者社区有图文教程：《使用工具生成软著申请所需的60页源代码文档》

**取哪 60 页**：建议前 30 页取 `lib/models/`、`lib/domain/`、`lib/store/`，
后 30 页取 `lib/pages/`、`lib/widgets/`。这两段恰好是"数据模型 + 业务逻辑"和"界面实现"，
独创性体现得最清楚。

**去敏**：提交前删掉或替换掉代码里的邮箱、密钥、内网地址、第三方 API Key。

### 1.6 在线申请 6 步

1. **前期准备**：确认软件已开发完成；明确著作权人（个人还是公司，决定交身份证还是营业执照）；备好源代码和说明书文档
2. **在线注册与填表**
   - 进中国版权保护中心官网 → 注册账号 → 实名认证
   - 选「软件登记」→「首次登记」→ 填写申请表
   - 重点字段：软件全称、简称、版本号、开发完成日期、首次发表日期、权利取得方式
3. **材料上传与提交**：上传源代码、说明书、身份证明，在线提交
4. **受理与审查**：形式审查通过 → 实质审查
5. **补正（如需）**：收到《补正通知书》后，务必在指定期限内修改重交（逾期视为撤回）
6. **制证与发证**：审查通过后制作证书，可邮寄领取、现场领取，或官网下载电子证书

### 1.8 常见补正原因（原文归纳的五大坑）

1. **源代码格式混乱** —— 补正原因第一名。没页眉、每页不足 50 行、没页码
2. **软件说明书内容空洞** —— 只有功能列表或纯截图，没有操作流程和设计思路
3. **权利归属信息矛盾** —— 公司名义申请却交个人身份证；开发完成日期晚于首次发表日期
4. **软件名称不规范** —— 过于宽泛、通用或含他人商标（避免写"XX管理系统""智能平台"这种）
5. **直接提交项目压缩包** —— 而不是排版好的文档

## 2. App 备案（工信部）

### 2.1 法律依据与强制程度

依据《工业和信息化部关于开展移动互联网应用程序备案工作的通知》，
**App 必须在上线前完成备案**。

落地表现：

- 华为、小米、OPPO、vivo、荣耀、应用宝：**上架时强制填写备案号**
- App Store 中国区：**必须填写 ICP 备案号**
- 华为 AGC 的 HarmonyOS 应用：同样需要

### 2.2 一个关键认知：你得先有一个"接入服务商"

备案不是你自己去工信部网站填表（**工信部备案系统没有给个人开放提交入口**），
而是**通过接入服务商（云厂商）代你提交给省通信管理局**。

**好消息**：阿里云官方明确说 —— **App 备案与网站备案是并列关系，不需要先做网站备案**。
未完成网站备案的主办者，可在一次申请里同时完成网站备案和 App 备案。

**但坏消息**：云厂商提交备案需要「**备案服务码**」，而这个码来自你名下的一台**云服务器实例**（ECS / 轻量应用服务器）。

所以个人开发者的务实路径是：

```
买域名（~10-40元/年）
   + 买最便宜的轻量应用服务器（~60-120元/年，选 3 个月以上时长）
   → 用它的备案服务码提交备案
   → 一次申请里同时做「网站备案」和「App 备案」
```

> 备案期间云服务器要保持有效（备案要求实例剩余时长 ≥ 3 个月），
> 但不要求你真的跑什么服务。备案完成后这台机器可以只当个静态页托管用。

### 2.3 具体去哪买、买什么

| 厂商 | 产品 | 大致价格 |
|---|---|---|
| 阿里云 | 域名 + 轻量应用服务器（2核2G，首年优惠） | 域名 10~40 元/年 + 服务器 60~120 元/年 |
| 腾讯云 | 域名 + 轻量应用服务器 | 同上量级 |

**实操**：

1. 注册云厂商**中国站**账号（阿里云国际站不支持 App 备案）
2. 完成**个人实名认证**（身份证 + 人脸）
3. 买域名 → 做**域名实名认证**（个人身份证，需 3~5 天核验）
4. 买 3 个月以上的轻量应用服务器
5. 进入云厂商的「ICP 备案」控制台 → 选择「新增备案」

### 2.4 三端特征信息怎么取（这一步最容易卡住，给具体命令）

备案时要按平台分别填写**包名、公钥、证书指纹**。三端要求不同：

| 平台 | 标识符 | 需填指纹 | 格式 |
|---|---|---|---|
| 安卓 | APK 包名 `com.bookmovie.revisit.app` | 证书 **MD5** | 16 进制，不区分大小写 |
| iOS | Bundle ID `com.bookmovie.revisit.app` | 证书 **SHA-1** | 16 进制 |
| 鸿蒙 | 包名 `com.bookmovie.revisit.app` | 证书 **MD5 指纹** | 16 进制 |

> ⚠️ 三端信息必须**填齐全**，只给 MD5 而缺包名或公钥，备案流程走不下去。

#### 安卓

先构建正式签名包（参考主 `README.md` 第四节的签名配置）：

```bash
flutter build apk --release
```

**方式 A（推荐）**：用云厂商备案系统里的「**备案智能助理**」，直接上传 APK 文件，
它会自动识别包名、签名、公钥，不用手填。

**方式 B（手动）**：

```bash
# 查看包名
aapt dump badging build/app/outputs/flutter-apk/app-release.apk

# 查看证书（含 MD5 指纹和公钥信息）
keytool -printcert -jarfile build/app/outputs/flutter-apk/app-release.apk
```

或下载 **JadxGUI** 打开 APK：

- 包名：`资源文件 → AndroidManifest.xml → package` 属性
- 公钥和 MD5 签名：`APK signature` 中的「模数（公钥）」和「MD5 签名」

**如果上传 APK 报「安装包无效」**：通常是因为 APK 经过加固、混淆或二次打包。
用**原始未加固的正式发布版 APK** 重传即可；实在不行可以跳过 APK 上传，
在「App 名称」输入框手动填写 App 名称完成备案。

#### iOS

1. 登录 https://developer.apple.com/cn/ （用该 App 对应的开发者账号）
2. **Bundle ID**：进「证书、标识符和描述文件」→「标识符」→ 找 **IDENTIFIER 列**
3. **公钥 + SHA-1**：进「证书」→ 下载该 App 的证书 → 双击导入钥匙串 →
   打开证书「显示简介」→ 展开「详细信息」→ 查看「公共密钥」和「SHA-1 指纹」
   - 公钥显示不全时，单击省略号展开；实在展开不了，复制省略号前能显示的部分填进去即可

**⚠️ 重大坑点**：**iOS 开发者证书有效期只有 1 年**。证书到期重新签发后，
如果**公钥或 SHA-1 发生变化，你必须走「变更备案」更新 App 特征信息**。

```
备案系统 →「我的备案」→ 目标备案记录点「变更」
→ 变更互联网信息服务 → 修改 App 特征信息中的公钥和 SHA-1 指纹
```

**建议在证书到期前 30 天内完成更新**，否则会出现"备案信息与实际证书不一致"，
影响 App 正常运行或商店审核。

#### 鸿蒙

1. 用鸿蒙应用对应的开发者账号登录 **AppGallery Connect (AGC)** →「我的项目」
2. 选择应用项目，在**应用区域查看包名**
3. 取公钥和数字指纹：
   - 进入「证书、APP ID 和 Profile」
   - 下载该鸿蒙应用的**开发者证书**
   - 用文本编辑器打开证书，**删除证书链部分，只保留最后一部分，然后保存**
   - 打开保存后的证书 →「详细信息 → 公钥」取公钥
   - 「详细信息 → 指纹」取签名指纹值（MD5）

### 2.5 提交流程（8 步）

1. **准备**：域名实名认证完成 + 云服务器实例有效 + 已有网站备案（没有就一起做）
2. 登录云厂商「ICP 代备案管理系统」→「开始备案」（账号下已有备案则点「新增/接入其他服务」）
3. 填写**主办者信息**（个人：姓名、身份证、手机、应急手机、邮箱）
4. 填写 **App 基础信息**
   - App 名称（安装后图标下方显示的名字，**在同一主办者下唯一**）
   - App 图标
   - App 内容分类
   - App 语言
   - 是否对外提供 SDK → 否
   - 调用的三方 SDK → 本项目无，填"无"
5. 点击「**添加运行平台**」，分别填三端特征信息
   - 安卓平台：包名 + 公钥 + 证书 MD5
   - iOS 平台：Bundle ID + 公钥 + 证书 SHA-1
   - 鸿蒙平台：包名 + 公钥 + 证书 MD5 指纹
   - **后台域名**：本项目是纯本地应用，没有后台服务。按云厂商表单实际要求填写，
     无后端时一般留空或填你备案的那个域名
6. 填写 **App 负责人信息**（可与主办者同一人）
7. **上传资料 + 真实性核验**（身份证、手持照或人脸核验）
8. 提交 → 云厂商初审 → **工信部短信核验**（务必在 24 小时内回复短信，否则订单被驳回）
   → 省通信管理局审核 → 下发备案号

**备案号形态**：`粤ICP备xxxxxxxx号-1A`（末尾的 A 表示 App）。
网站备案号是 `-1`，App 是 `-1A`，是两个不同的号。

**审核时长**：管局法定审核时限 20 个工作日以内，实际常见 5~15 个工作日。

### 2.6 三端要备案几次？

| 情况 | 结果 |
|---|---|
| 安卓 / iOS / 鸿蒙 **使用相同名称** | **只备案一次**，发一个备案号 |
| 不同平台用**不同名称** | 按不同 App 多次备案，发多个备案号 |

我们的三端都叫「书影温故」，所以**一次备案搞定**。

### 2.7 常见驳回原因

| 驳回原因 | 怎么避免 |
|---|---|
| 未及时回复工信部核验短信 | 提交后 24 小时盯着手机，收到 12381 短信立刻回复 |
| App 名称与软著/商店名称差异过大 | 三者保持一致（见 0.3 节） |
| 特征信息填错或不全 | 用备案智能助理上传 APK 自动识别，别手抄 MD5 |
| 域名未实名认证 / 未备案 | 域名实名务必提前 3~5 天做 |
| 云服务器剩余时长不足 3 个月 | 续费到 3 个月以上再提交 |
| 涉及新闻/出版/教育/影视/宗教等特殊内容 | 需额外交主管部门审核文件（我们这款不属于） |
| 备案负责人手机号与实名不符 | 用本人实名手机号 |

### 2.8 华为侧的 APP 核准

华为在 AGC 提供了《APP 核准（APP备案）指引》：首次核准时，
**按实际上架平台选择平台类型**（上架鸿蒙平台就选鸿蒙平台，并添加鸿蒙包信息）。

你可以选择：

- 用已在阿里云/腾讯云办好的备案号，直接填进 AGC，或
- 按华为的指引在华为侧提交备案

两者都行，具体以 AGC 页面实时提示为准。

## 3. 隐私政策

### 3.1 硬要求

| 要求 | 说明 |
|---|---|
| 有可公网访问的 URL | 所有商店都要填这个链接 |
| App 内必须能访问 | **首次启动要弹窗提示并让用户同意**，且设置页要常驻入口（这是审核重灾区） |
| 内容真实 | 写"不收集"就必须真的不收集，市场会核对权限列表和 SDK 列表 |

**本项目的好消息**：这是一个完全离线的本地应用（数据存在 `shared_preferences`），
不联网、不登录、无广告、无第三方统计 SDK、无崩溃上报。
所以隐私政策可以写得非常短，而且审核最容易过。

### 3.2 隐私政策托管（免费，10 分钟）

任选一种：

| 方案 | 做法 | 成本 |
|---|---|---|
| **GitHub Pages** | 建仓库 → 放 `privacy.md` 或 `index.html` → Settings → Pages 开启 | 免费 |
| **Gitee Pages** | 同上（国内访问更快，但需实名） | 免费 |
| **Cloudflare Pages** | 连接 GitHub 仓库自动部署 | 免费 |
| **Notion 公开页** | 直接分享公开链接 | 免费（但部分市场不认，建议用上面几种） |

得到形如 `https://你的用户名.github.io/shuying-privacy/` 的链接，填进所有商店。

### 3.4 App 内需要做的改动（审核会查）

发布前必须在 Flutter 应用里加上：

1. **首次启动的隐私政策弹窗** —— 用户点"同意"才能进入主界面；
   必须提供"不同意"时能做什么的说明（本应用不收集数据，可直接退出应用）
2. **设置/关于页常驻入口** —— 点击可在应用内打开隐私政策全文
3. **Android release 包不要声明 INTERNET 权限** —— Flutter 模板默认只在
   `android/app/src/debug/AndroidManifest.xml` 和 `profile` 里加 INTERNET 权限，
   `main/AndroidManifest.xml` 里不要加。这样商店读取到的权限列表是空的，审核最顺
4. **iOS Info.plist 不要加无用的用途描述** —— 不加就不会触发对应权限询问

> 上面第 1、2 点**工程里已经实现**：
> 首启同意弹窗在 `lib/pages/privacy_consent_gate.dart`，
> 设置页常驻入口 + 撤回同意在 `lib/pages/settings_page.dart`，
> 隐私政策全文在 `lib/pages/privacy_policy_page.dart`
> （`PrivacyPolicyPage.version` 需与公网页面、商店提交版本保持一致）。
> 第 3、4 点属于平台工程生成后的配置项，见主 `README.md` 第三节。

## 6. 常见坑速查

| 现象 | 原因 | 解决 |
|---|---|---|
| 软著被要求补正 | 源代码没页眉/每页不足 50 行/无页码 | 用工具重新排版 |
| 软著被驳回 | 开发完成日期晚于首次发表日期 | 改日期，前者必须 ≤ 后者 |
| 备案提交后无进展 | 没回工信部核验短信 | 24 小时内回复 12381 短信 |
| 备案被驳回 | 找不到接入服务商 / 没有云服务器 | 先买域名 + 轻量服务器 |
| 备案被驳回 | App 名称与软著名称差异过大 | 三者统一命名 |
| 备案填不出指纹 | 没做正式签名包 | 先生成 release 签名包再取 MD5/SHA-1 |
| 上架被驳回 | App 内没有隐私政策入口 | 加首次启动弹窗 + 设置页入口 |
| 上架被驳回 | 权限列表有 INTERNET 但声称不联网 | 检查 `main/AndroidManifest.xml` |
| iOS 证书续期后异常 | 公钥/SHA-1 变了但备案没改 | 走「变更备案」更新特征信息 |
| 华为后台找不到鸿蒙应用 | 安卓和鸿蒙是两个独立条目 | AGC 里分别新建 |
| 更新版本时上传失败 | 构建号没递增 | `pubspec.yaml` 的 `+N` 每次必须 +1 |
| 无法更新已上架 App | 签名密钥丢失 | **无解，只能换包名重发** |
