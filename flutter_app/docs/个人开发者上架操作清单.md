## 1. D0 当天：四件「有等待期」的事（★ 最优先，今天不启动就晚一天）

这四件事都有 1~5 天审核等待，且**互不影响、可以同一天全部提交**。

### 1.1 Apple Developer Program（iOS 唯一收费项，688 元/年）

**去哪**：iPhone/iPad 装 **Apple Developer** App（推荐，中国大陆实名走 App 更顺）
或用网页 https://developer.apple.com/programs/enroll/

**准备材料**：身份证原件、本人手机号、一张信用卡/支付宝（扣 688 元）、**建议新注册一个专用 Apple ID**（别用日常号）

**步骤**：

1. 注册 Apple ID → 设置里**开启双重认证**（不开无法注册）
2. Apple Developer App → `Account` → 登录 → `Enroll`
3. 选 **Individual（个人）** ← 企业才选 Organization
4. 填真实姓名（**拼音必须与身份证完全一致**）、地址、电话
5. 身份验证：身份证正反面拍照 + 人脸扫描
6. 同意《Apple Developer Program 许可协议》→ 支付 688 元
7. 等审核邮件，通常 1~3 天

**个人账号的两个后果（提前知道）**：
- App Store 上「开发者」一栏显示的是**你的真实姓名拼音**，无法自定义（只有企业号显示公司名）
- 不需要 D-U-N-S 邓白氏编码（企业号才需要，且要 1~5 工作日）

**通过后立刻做 6 件事**（App Store Connect https://appstoreconnect.apple.com）：

- [ ] 我的 App → `+` → 新建 App：平台 `iOS`、名称 `书影温故`、主要语言 `简体中文`、Bundle ID `com.bookmovie.revisit.app`、SKU `shuyingwengu001`
- [ ] 开发者后台 → `Certificates, Identifiers & Profiles` → Identifiers 新建 App ID（**Explicit**），填 `com.bookmovie.revisit.app`
- [ ] 协议、税务和银行业务 → 签 **Free Apps 协议**（免费 App 也必须签，否则无法上架）
- [ ] 证书与描述文件：留到 Mac 上生成（见 §5）
- [ ] App 隐私「营养标签」：选 **不收集任何数据**
- [ ] 记下审核通过日期，证书有效期 3 年、描述文件 1 年

### 1.2 华为开发者联盟（免费，管鸿蒙 + 华为应用市场）

**去哪**：https://developer.huawei.com/consumer/cn/

**步骤**：

1. 注册（手机号或邮箱）→ 登录
2. 右上角账号 → **实名认证** → 选 **个人开发者**
3. 填：真实姓名、身份证号、手机号 → 人脸核验
4. 等 1~3 天

### 1.3 域名 + 云服务器（备案的硬前置）

**去哪**：阿里云 https://www.aliyun.com **或** 腾讯云 https://cloud.tencent.com
⚠️ **只选一家，全程只用这一家**；必须**中国站**（国际站不支持 App 备案）

- [ ] 买域名（`.com` 或 `.cn`，10~40 元/年）
- [ ] **立刻提交域名实名认证**（3~5 天核验 —— **这是备案的第一道排队，今天不提交就晚一天**）
- [ ] 买轻量应用服务器（**剩余时长 ≥ 3 个月**，60~120 元/年，最便宜那档即可）
- [ ] 备案控制台 → 领「**备案服务码**」（后面 ICP 备案要用）

### 1.4 软著 / 电子版权（安卓各渠道的入场券）

**去哪**（三选一）：

| 通道 | 网址 | 费用 | 周期 | 适合 |

| 代办加急 | 淘宝/代办机构 | 300~1500 元 | 3~7 天 | 赶时间 |

**个人申请要准备**：

- [ ] 身份证正反面扫描件
- [ ] 源码文档：前后各 30 页，共 60 页（Word，排版格式见 `上架前置资质与备案指引.md` 第 1 节）

- [ ] 申请表：软件名称填 **`书影温故`**，著作权人填**你的真实姓名**

- [ ] 提交后记录**受理号**：____________

> 安卓各渠道（小米/OPPO/vivo/荣耀/应用宝）注册时**必须上传软著证书**，所以要先拿到它再注册（§3）。

## 4. D3：Mac 上生成平台目录 + 三端签名（★ Windows 不做这步）

> 见 `双机分工与交接清单.md` 方案 A：**三端平台目录只在 Mac 生成一次**，Windows 全程不碰。

```bash
# 1. 取代码（仓库根是 APPdev，flutter_app 是子目录）
git clone <你的仓库地址> && cd <仓库>/flutter_app
flutter pub get

# 2. 一次生成三端平台目录
chmod +x tool/bootstrap.sh
./tool/bootstrap.sh com.bookmovie.revisit.app

# 3. 放签名密钥（U 盘从 Windows 带过来的 .jks，不要重新生成！）
cp /Volumes/<U盘>/shuyingwengu-release.jks ~/keys/
./tool/gen-keystore.sh --check        # 期望：✅ 一致

# 4. 核对三端标识符都等于 com.bookmovie.revisit.app
grep applicationId android/app/build.gradle.kts
grep PRODUCT_BUNDLE_IDENTIFIER ios/Runner.xcodeproj/project.pbxproj | head -3
grep bundleName ohos/AppScope/app.json5
```

然后把三端**显示名**都设成 `书影温故`：

| 平台 | 文件 | 字段 |
|---|---|---|
| Android | `android/app/src/main/AndroidManifest.xml` | `android:label` |
| iOS | `ios/Runner/Info.plist` | `CFBundleDisplayName` |
| HarmonyOS | `ohos/entry/src/main/resources/base/element/string.json` | `app_name` |

## 5. D3~D20：App 备案（★ 全程在这台 Windows 上做，与机器无关）

前置：域名实名通过 ✅ + 服务器 ≥3 个月 ✅ + 至少一个平台特征信息（安卓 ✅ 已有）

**去哪**：你在 §1.3 选的那家云厂商 → 「ICP 代备案管理系统」

- [ ] 新增备案 → 主办者性质选 **个人**
- [ ] 主办者信息：姓名、身份证号、手机、应急手机、**邮箱 `380174722@qq.com`**
- [ ] App 基础信息：名称 `书影温故`、图标、分类、语言
- [ ] 添加运行平台 → **安卓**：抄 `tool/keystore-fingerprint.txt` 里的 **MD5** 和**公钥**
- [ ] 添加运行平台 → **鸿蒙**：AGC 下载开发者证书 → 取 **MD5** 和**公钥**（证书文件用文本编辑器打开，**删掉证书链只留最后一段**再看详细信息）
- [ ] 添加运行平台 → **iOS**：先跳过，等 Mac 上出了证书取到 **SHA-1** 后走「变更备案」补
- [ ] 提交 → 云厂商初审（1~2 天）
- [ ] ⚠️ **盯手机：12381 短信必须 24 小时内回复**，超时驳回重来
- [ ] 管局审核（通常 7~20 天）→ 拿到**备案号**

## 6. 材料齐后：依次提交上架

顺序：**AGC（鸿蒙）→ 各安卓市场 → App Store**

### 6.1 鸿蒙（AGC）

- [ ] AGC → 新建应用 → 类型 **HarmonyOS 应用**，包名 `com.bookmovie.revisit.app`
- [ ] 「证书、APP ID 和 Profile」→ 新建**发布证书**（上传 CSR 得 `.cer`）→ 生成 `.p12` → 创建发布 Profile 得 `.p7b`
- [ ] ⚠️ **`.p12` 密钥库口令必须记牢，丢了无法更新**
- [ ] DevEco Studio → `File → Project Structure → Signing Configs` 填入，或勾「自动生成签名」
- [ ] 填备案号、隐私政策 URL、软著 → 提交审核

### 6.2 安卓各市场

每个市场填：应用名 `书影温故`、包名、APK、图标、截图、**备案号**、**软著证书**、隐私政策 URL。
APK 用：`flutter build apk --release --split-per-abi`（国内上架用 APK）

### 6.3 iOS（App Store）

- [ ] Xcode：`open ios/Runner.xcworkspace` → Runner Target → Signing & Capabilities
      → 勾 `Automatically manage signing` → Team 选你的账号 → Bundle Identifier 填 `com.bookmovie.revisit.app`
- [ ] `flutter build ipa` → 用 **Transporter**（Mac App Store 免费）上传
- [ ] App Store Connect 填：名称、副标题、描述、关键词、截图、**隐私政策 URL**、**备案号**
- [ ] 隐私营养标签：选**不收集任何数据**
- [ ] 审核问答里说明：数据仅存本地、无网络请求、无第三方 SDK
- [ ] ⚠️ 每次提交前 `pubspec.yaml` 的 `version` **必须递增**，并同步设置页里硬编码的版本号
