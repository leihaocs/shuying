## 一、通用八步（每家都这套）

```
1. 注册开发者账号 → 完成实名认证（个人）
2. 创建应用条目 → 填包名/名称/分类/免费
3. 上传 release APK → 等后台自动解析
4. 核对解析结果（包名/版本/签名/权限）与 §0.5 一致
5. 填资料：图标、截图、简介、介绍、分级、客服、备案号
6. 传资质：软著证书（或受理证明）
7. 填审核说明（无测试账号 + 五步路径）
8. 提交审核 → 通过后按后台发布
```

**三条通用铁律**：

- ❌ **绝不勾"独家 / 首发 / 首发联盟"** —— 会限制其他渠道同步上架
- ❌ **不传 debug 包** —— 带 INTERNET 权限会让隐私申报与实际不符
- ✅ **加固/渠道重签名可选** —— 商店二次签名不影响版本号规则，但加固后必须**重新下载安装验收一次**

## 二、小米应用商店（优先做）

| 步骤 | 操作 |
|---|---|
| **入口** | 小米开放平台 https://dev.mi.com/ → 应用分发 |
| **账号实名** | 小米账号 → 个人开发者认证：身份证正反面、姓名、手机号；部分需人脸核验 |
| **创建应用** | 包名 `com.bookmovie.revisit.app`；名称"书影温故"；分类选**工具/效率**；免费下载 |
| **上传 APK** | 传 `app-direct-release.apk`（fat 包，含 arm64，小米 64 位要求满足） |
| **资料** | 图标 512×512；截图 1080×1920，3–5 张，无水印/黑边；一句话简介 + 详细介绍；客服邮箱；隐私政策 URL |
| **资质** | **软件著作权登记证书**（个人开发者）；部分类目接受电子版软著。软著下证前可先试传受理通知书，不通过就等证书 |
| **合规** | 隐私政策弹窗 + 同意（已有）；权限声明如实填"不申请敏感权限"；填 APP 备案号 |
| **审核说明** | 用 §0.3 那段 |

**常见驳回**：图标不合规（圆角/透明/带字）；截图与实际界面不符；隐私政策链接打不开；名称含极限词。

**时长**：1–3 工作日。

## 八、Google Play（单独体系，并行推进）

### 8.1 与国内渠道的关键差异

| 项 | 国内渠道 | Google Play |
|---|---|---|
| 包格式 | **APK**（direct） | **AAB**（必须用 `play` flavor） |
| 版本计数 | 各自独立 | **独立计数**，也可从 5 开始 |
| 签名 | 本地密钥 | **Play App Signing**，Google 托管/再签名 |
| 付费 | 已关闭 | 有 Play Billing（另配置商品与测试） |

**不能复用 `app-direct-release.apk`**，Play 必须用：

```bash
flutter build appbundle --release --flavor play
```

### 8.2 流程

1. Play Console https://play.google.com/console 注册（一次性 $25）
2. 完成**开发者身份核验**（个人：官方证件 + 邮箱 + 电话）
3. 创建应用 → 填应用详情（名称、简介、详细描述、图标、特色图片、截图）
4. **数据安全表单**：可声明**不收集、不共享任何数据**（release 包无 INTERNET，属实）
5. 内容分级问卷、目标受众与广告声明（无广告）
6. 上传 AAB → 核对解析出的包名/版本/权限
7. **新个人开发者账号通常需先做封闭测试（约 20 名测试者 / 14 天）** 才能申请正式发布 —— 以控制台实际提示为准
8. 目标 API 已达标（targetSdk 36）
9. 提交审核

### 8.3 一个容易踩的点

Play 启用 App Signing 后，**用户拿到的包是 Google 用其分发证书签的**，其指纹与本机 `.jks` 的 MD5/SHA256 不同。若后续要做合规/备案核对，**应该用 Google 控制台里显示的分发证书指纹**，不要直接沿用 `95:D2:…:FD`。

## 九、各渠道常见驳回原因速查（提审前逐条对照）

| 驳回原因 | 规避 |
|---|---|
| 隐私政策 URL 打不开 / 与应用行为不符 | 手机 4G 实测两个 URL；确保"不收集数据"表述与实际一致 |
| 权限声明与实际不符 | 我们无权限，照实填；**别照抄模板勾权限** |
| 截图有黑边、水印、非本应用界面 | 用 `huawei-20261024-1080x1920/` 或 `android-9-16/` 真机图 |
| 图标不规范（尺寸/圆角/透明/含文字） | 512×512 PNG |
| APP 备案号缺失或与包名不符 | 填 `粤ICP备2026143055号-2A` 并与阿里云登记核对 |
| 应用内存在不可用购买入口 | direct 包已隐藏；**文案也不能写"可购买会员"** |
| 名称含"官方/第一/最佳"等极限词 | 用"书影温故" |
| 软著证书上的名称/著作权人与应用不符 | 下证后核对；不一致先更正再提交 |

## 十、上架后动作

1. **商店下载安装验收**：每个渠道发布后，从**该商店真实下载安装**跑一遍核心流程（新增书籍/电影 → 统计 → 备份导出/合并导入 → 重启保留）
2. **公安联网备案**：APP 那条已于 2026-10-24 提交南山区网安大队，30 个自然日内审核；**网站那条**等 `bookmovie-revisit.cn` 开通后 30 日内办理
3. **网站部署**：只在网站备案通过后才解析域名、放行 80/443、配 HTTPS、页脚挂网站备案号
4. **版本更新**：`git pull` → 按要求累加 `+N` → 出包 → commit + push `pubspec.yaml` → 归档 `dist/1.0.0+N/`
