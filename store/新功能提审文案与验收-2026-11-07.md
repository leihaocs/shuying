## 可用于商店的文案草案

各后台字段长度不同，提交时按实际限制裁剪。只使用本次候选包实际包含并验收的能力，不把源码更新当成用户已收到的更新。

### 通用简短介绍

> 把读过的书、看过的电影，留成自己的书影档案。记录阅读进度、重读与重看感想，用搜索、标签和月度回顾找回那些值得温故的时刻。

### 通用功能介绍

> 书影温故是一款无需注册应用账号的私人书影记录工具。书架和电影分别整理，支持同一本书多轮阅读、同一电影多次观看，记录时间、10 分制评分与感想。
>
> 通过关键词、分类、标签和评分条件查找记录；免费查看基础统计与月度回顾，保存基础月度卡片或复制文字。记录保存在本机，可免费导出 JSON 并在其他设备合并导入，不会自动云同步。

“评分与感想”不表示每轮书籍都有独立评分：书籍目前保存全书评分；电影保存每次观影评分。不要将本产品写成自动检索书影资料、扫码识别、计时器、提醒、云同步或跨平台统一会员，这些不是本轮能力。

### 国内安卓 / HarmonyOS 补充段落

> 设置中提供高级功能预览，可以先看看自己的年度汇总、日期范围和跨年回顾，或对照最近两次重读、重看的感受。当前渠道暂不开放购买；基础记录、月度回顾、基础卡片和 JSON 备份免费使用。

不要在该渠道文案、截图或审核备注中写“立即购买 Pro”“永久会员已开放”，也不要展示其他渠道的购买价格。

### iOS / Google Play 的 Pro 补充段落

仅对确实开放购买且已验收的候选使用：

> Pro 在基础记录之外提供年度趋势、任选日期范围汇总、跨年对比，以及同一本书历轮阅读、同一电影历次观影的对照。完整回顾可复制文字、保存图片或导出 PDF。购买及恢复以当前商店账号和实际开放能力为准，记录备份不迁移 Pro 权益。

价格只填写当前商店实际返回的报价，不写死报告中的建议实验价格。不宣传“一次购买三端通用”，也不将永久买断改写为订阅。未开放购买的 Play 构建使用上面的“高级功能预览”口径。

### 本次更新说明草案

1. 搜索可与分类、标签和评分条件组合，查找书影更方便。
2. 免费月度回顾支持按年月查看，基础卡片可保存、分享，文字可复制。
3. 新增高级日期范围、跨年和历次感想对照；有记录时优先展示真实预览。
4. 完善备份冲突处理、大文件确认和本机副本恢复入口，保持 JSON 备份免费。
5. 改善购买异常等待与结果恢复，撤回隐私同意后停止相应自动商店查询。

第 3、5 项对国内渠道应说明“高级功能仅预览，未开放购买”。不要用“彻底杜绝审核驳回”“所有设备均无问题”等无法保证的表述。

## 能力的准确口径

| 功能 | 当前实现与文案边界 |
|---|---|
| 搜索 | 书籍按书名、作者、出版社/版本、标签及书籍备注查找；电影按片名、导演、年份、标签及电影备注查找。支持中文关键词和英文大小写不敏感匹配；不宣称已全文搜索每笔历史感想。 |
| 标签 / 评分 | 标签可在资料表单编辑；评分可选未评分或 1～10 分下限，与关键词、分类叠加。书籍按全书评分；电影按最近一次观影评分筛选，不是历史均分。分类角标仍显示全库分类数量。 |
| 分类 | 书籍的想读、在读、再次阅读、已读互斥；电影的想看、已看一次、多次观看互斥。“全部”是汇总视图。 |
| 免费月度 | 可切换年月，沿用统计页的书籍 / 电影范围；基础卡片只有汇总数字，不含书名、片名或个人感想。图片保存与系统分享需下次真机核验。 |
| 真实高级预览 | 年度默认最近有记录的年份；无阅读或观影记录时才使用明确标注的独立样例。范围预览固定最近记录所在的 30 天及相邻年份，不能自由修改范围；历次预览展示最近两次。样例不写入本机记录。 |
| Pro 完整回顾 | 可选择日期与年份、查看完整历次对照并导出。导出组件与服务均核验 Pro；不能用页面参数或 JSON 备份解锁。 |
| 书籍历轮对照 | 显示开始、结束时间、本轮累计页数、累计时长与感想；仅当前轮次显示已有进度。全书评分单独展示，不伪造历史逐轮评分。 |
| 电影历次对照 | 按真实观看时间倒序，展示每次实际评分、感想及与上次评分的变化；未评分不当作零分。 |
| 日期 / 累计统计 | 范围首尾日均包含。独立校正的累计量按本轮结束或最近记录日期归属，不与单次量双算；缺少逐日分配的累计量不伪装成每天均摊数据。 |
| 图片 / PDF | Pro 图片提供暖纸与夜色样式；长内容转用分页 PDF。PDF 是按 A4 页面保存的图像型报告，不承诺可检索或选择文字；完整文字另有复制。过长内容会提示，不静默截断当成完整报告。 |
| JSON | 免费，导出本机原始记录；新备份 schema 3 含标签，仍读旧 schema 1、2。旧应用可能不支持新备份。合并不是自动双向同步，删除也不自动传播。 |
