## 2. 可复制的商店介绍

**简短介绍：**

> 记录阅读与观影，留住重读重看的感受，用搜索、标签和月度回顾整理私人书影档案。

**详细介绍：**

> 书影温故是一款无需注册应用账号的阅读与观影记录工具。把读过的书、看过的电影和再次回看时的感受，整理成自己的书影档案。
>
> - 书籍与电影分别管理，分类清楚，支持搜索、标签与评分筛选。
> - 同一本书可记录多轮阅读，区分阅读进度、单次记录与本轮累计页数、时长。
> - 同一部电影可记录多次观看，每次保留实际时间、10 分制评分及感想。
> - 免费查看基础统计和月度回顾，复制回顾文字、保存或主动分享基础月度卡片。
> - 通过免费 JSON 备份导出、导入或按书选择合并，便于自己保管记录。
> - 支持随系统、浅色与深色主题。
>
> 书影记录保存在本机，不会自动上传开发者服务器。当前不提供云同步、图书全文或影片播放，也没有公共社区。
>
> 本次 Google Play 测试版免费下载，基础记录、搜索、月度回顾和 JSON 备份免费。高级年度、日期范围及历次对照提供预览，暂不开放 Pro 购买；完整高级报告不属于本轮免费开放功能。
>
> 卸载或更换设备前请自行导出备份。用户主动选择文件服务或分享接收应用时，该服务会获得所选导出内容，请在操作前核对。

**测试版更新说明草稿：**

> 本次测试重点：书影搜索与标签筛选、月度回顾、基础卡片保存与分享，以及 JSON 备份、合并和恢复体验。欢迎反馈记录时间、阅读累计数据、界面显示或文件操作的问题。当前暂不开放 Pro 购买。

## 4. 权限、SDK 与数据安全核对稿

封闭测试也需要数据安全表单；仅在内部轨道发布的例外不适用于随后封测。申报需覆盖 SDK 的实际行为及同包名各有效 Play 版本。[Google 数据安全填写说明](https://support.google.com/googleplay/android-developer/answer/10787469?hl=zh-Hans)

### 当前源码证据

| 路径 / 行为 | 已核对事实 | 最终候选仍需确认 |
|---|---|---|
| `android/app/src/main/AndroidManifest.xml` | 主清单没有相机、位置、通讯录、麦克风、通知或广泛文件访问权限；分享 FileProvider 不导出，只开放临时读取所选 PNG | 依赖会参与清单合并；不可只凭主清单宣布最终包“零权限” |
| `android/app/build.gradle.kts` | `playImplementation` 保留 Billing `8.3.0`；本地缓存 AAR 清单声明 `com.android.vending.BILLING` | 核对最终合并清单、依赖和 Console 报告；免费不代表 SDK 已移除 |
| Play `StorePurchases.kt` | 初始化会构造 BillingClient；**`PLAY_LICENSE_KEY` 为空时，在连接前返回购买关闭 / 未购，购买恢复不可用** | 构建配置确认公钥未注入，并实测不查询商品/订单、不显示购买或恢复按钮 |
| `SignedPurchaseCache.kt` | 仅真实验签且确认的购买交付路径写入本机加密凭证；不放入业务 JSON | 本轮免费路径不应产生凭证；不能把已有缓存代码写成免费包已经采集订单 |
| `MainActivity.kt` 文件接口 | JSON / PNG / PDF 使用系统选择器，只读写用户所选文件；基础卡片由用户主动调用系统分享 | 取消、重试、接收方可读取和实际文件类型；PDF 完整报告仍受 Pro 边界约束 |
| Dart 记录及偏好 | 私有本地 JSON、shared_preferences；本次源码未发现自建记录上传、广告、分析或崩溃上报 SDK | 新增依赖、最终包及实际网络行为再次确认；不能由静态搜索保证所有 SDK 永远不传数据 |

系统文档选择器提供用户选定文件的访问，不需要为此申请广泛存储权限。[Android 官方存储访问框架](https://developer.android.com/training/data-storage/shared/documents-files?hl=zh-cn)

### 数据安全按实际问题填写

以下是本项目的判断依据，**不是可一键提交的全“否”表单**：

| 数据 / 问题 | 免费候选的填写依据 |
|---|---|
| 书影、评分、阅读时间与感想 | 当前仅在本机保存处理；核对候选没有后台上传后，按“仅本机处理”规则评估。不要因为用户录入了文字，就自动当作向开发者收集 |
| 主动保存/分享导出内容 | 用户选择的文件服务/接收应用可取得内容。若确属用户明确发起且合理预期的分享，可按相应分享例外评估；若以后自动上传则重新声明 |
| 银行卡、付款账户 | 当前免费路径不发起支付，也不访问银行卡资料。未来商店直接处理卡号与应用收到购买记录须分开评估，不能把“未接触卡号”扩展成“没有任何交易数据” |
| 设备标识符、诊断及应用互动 | 本次源码没有广告/统计 SDK 或主动读取这些信息的实现；仍核对最终 SDK 的实际行为，不能只凭 SDK 名称推断采集或不采集 |
| 是否收集/分享任何规定的数据类型 | 完成以上核对及所有有效 Play 版本汇总后，才能作最终回答；发现任何需申报行为，逐类型填写用途、必需/可选等后续问题 |
| 账号创建 | 应用内无账号创建。不要把 Google Play 系统账号当成本应用账号 |
| 删除与删除请求 | 可在设置清空本机记录，导出文件由用户管理。若表单出现删除请求问题，按实际提供的应用内功能/联系邮箱及题干回答，不声称可远程删除第三方存储或商店订单 |
| 传输加密 / 独立审核等 | 仅本地加密缓存不等于所有传输已加密；只有确认存在的传输及安全机制才勾选。没有独立安全审核，不声明已认证 |

上表对仅本地处理、用户主动分享及支付服务的判断，依据[Google 官方数据安全定义与常见问题](https://support.google.com/googleplay/android-developer/answer/10787469?hl=zh-Hans)。权限清单和实际数据收集是不同证据；有 Billing 权限不自动表示发生购买，购买关闭也不能代替 SDK 行为核对。
