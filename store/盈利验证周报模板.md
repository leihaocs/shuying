用于人工整理商店后台与用户自愿反馈。无需接入行为分析、广告或新账号 SDK；本模板不自动采集数据、联系用户、调整价格或修改商店后台。

本周目标：____。代码批次 / 实际在架版本：____。只填真实已取得的数据；未知写“未取得”，未开售写“不适用”，确认真实为零才填 0。公开评分为 0 不等于下载为 0。

填写规则：

1. “退款前毛销售额”记录本周成功交易的用户实际支付金额合计，注明原报表是否含税及是否已净扣项目；若后台只提供预计开发者收益，不将它冒充毛销售额，也不强行倒推。
2. 本周退款可能来自往周订单，单列发生日期和对应购买周期。“本周退款事件数 ÷ 本周购买数”不能称为同批用户退款率。
3. 如追踪某周成交的退款率，单独记录该批成功订单数、截至何日的已退款订单数、观察窗口是否完整。订单与人数不要混用。
4. 毛销售额、扣退款后的交易额、商店预计收益和实际到账是不同数字，不能都称“利润”。不要统一假定扣 15% 就是净收入；平台费用、税费、退款和实际开支按真实报表分开记录。
5. 永久买断不按月重复向同一批已购用户计收入。恢复购买不是第二笔销售；跨商店也不据 JSON 导入认定为同一付费用户。

## 价格与发布决策栏

**当前价格保持不变，以商店实际报价为准。** 原审查报告的价格区间只是候选实验，不是自动改价授权。新增高级功能也不自动开启国内购买、Play 商家配置或订阅。
