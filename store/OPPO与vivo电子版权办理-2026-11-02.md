# OPPO / vivo 上架「电子版权证书」办理说明 · 2026-11-02

> 11/5 修订：vivo 已上架，OPPO 沿用等待正式软著的决定，不新增收费认证。官方上传流程同时列电子版和纸质版权类型；本文只需办理电子版权、一张覆盖所有渠道、费用周期及法律用途等概括不作为现行结论，详见[最新个人主体计划](个人主体安卓发布计划-2026-11-05.md)。

## 一、结论先说

OPPO 要的不是你已经提交的那个「正式软著」，而是**《APP 电子版权认证证书》**——第三方平台（电子版权认证联合服务平台，业内俗称「易版权」）基于区块链存证出具的证书，**个人主体可办，约 600 元，普通 10–15 个工作日出证，加急最快 1–3 个工作日**。你 10-22 提交的正式软著官方审查要 1–2 个月，等不及；电子版权的定位就是「软著下证前的上架过渡件」，OPPO / vivo / 华为 / 应用宝都已接入核验接口。

**一张证书多家复用**：OPPO、vivo、应用宝、华为认的是同一张，办一次即可覆盖当前 P1 全线，不用每家各办。

## 二、OPPO 官方原文要求（开放平台「应用上传流程」）

资质信息栏「软件版权证书」：

| 类型 | 规范 |
|---|---|
| 电子版 | **必须**上传由「电子版权证书官方申请通道」申请的电子版权证书；《APP 电子版权认证证书》+《软件著作权认证证书》**双页一起提供**，仅支持 PDF，≤20MB |
| 纸质版 | 非电子版权通道申请的证书（即正式软著登记证书）走这里，JPG/PNG，≤20MB |

配套项：「软著归属权」自研 / 授权；「免责承诺函」（通用承诺函，JPG/PNG ≤1M）；「隐私政策网址」；「ICP 备案」（**网站 ICP 备案，不是 APP 备案**，主体须与账号认证主体一致）。

关键点：OPPO 明确写了「必须上传由**电子版权证书官方申请通道**申请的」，所以不要自己随便找一家代办——**从 OPPO 后台该栏目的入口链接进去办**，保证是被认可的通道。

## 三、电子版权认证 vs 正式软著

| 维度 | 电子版权认证证书 | 正式软著（中国版权保护中心） |
|---|---|---|
| 发证方 | 电子版权认证联合服务平台（区块链存证） | 国家版权局 / 中国版权保护中心 |
| 办理周期 | 普通 10–15 工作日；加急最快 1–3 工作日 | 受理后 60 日内审查，实际 1–2 个月 |
| 费用 | 市场化收费，约 600 元（加急更贵，以平台当时报价为准） | 官方登记费自 2017 年起停收，自行办理免费；代理 300–600，加急 600–3000 |
| 用途 | **仅**移动应用上架审核 | 上架 + 高企认定 + 双软 + 税收优惠 + 招投标 + 司法维权 |
| 法律效力 | 证据存证性质，不能单独作为维权核心证据 | 国家公信力，司法采信度高 |
| 形式 | 电子证书，**双页关联**（电子版权页 + 软著认证页），不可分割使用 | 电子证书（PDF，带电子签章） |

两者**不互相替代**，建议并行：电子版权抢上架，正式软著继续等（你 10-22 已提交，需自行到登记后台核受理号/补正状态）。

## 四、办理路径（按此顺序做）

1. 登录 OPPO 开放平台 → 应用服务 → 创建应用 → 资料填写 → **资质信息「软件版权证书」** → 点「电子版权证书官方申请通道」跳转。
2. 在认证平台提交（个人主体）：
   - 申请人身份证
   - 软件名称：**书影温故**（必须与上架应用名完全一致）
   - 版本号：与上架包一致（当前 1.0.0）
   - 软件操作说明书（PDF）
   - 源代码**前 30 页 + 后 30 页**（页眉标注软件名称与版本号，每页约 50 行）
3. 付费出证，下载双页 PDF。
4. 回到 OPPO 后台上传：双页 PDF 一起传，≤20MB；同时填通用承诺函、隐私政策网址、ICP 备案号（用 bookmovie-revisit.cn 的网站 ICP 备案，非 APP 备案）。
5. 同一份证书复用到 vivo、应用宝；华为已上架，如需补登再传。

## 六、避坑清单

- **名称必须一致**：证书软件名 = 商店上架名 = 「书影温故」，一字之差驳回。
- **主体必须一致**：证书著作权人姓名 = OPPO 账号实名认证主体 = 软著归属「自研」。
- **双页一起传**：只传一页会被打回；这是电子版权证书的双页关联设计。
- **格式**：PDF，≤20MB；承诺函 JPG/PNG ≤1M。
- **ICP 备案填网站的**，不是 APP 备案号，主体要与账号一致。
- 电子版权**不能**用于高企认定、补贴申报、维权，只是上架件；正式软著别撤，继续走。
