## 二、App Store（iOS）

**名称**：书影温故（如被占用用「书影温故 - 读书观影记录」）

**副标题**：读书进度与观影记录，一目了然

**关键词**（逗号分隔，不含空格，≤100 字符）：

```
读书,阅读,书籍,书架,书单,进度,笔记,观影,电影,片单,记录,统计,书评,影评,打卡
```

**描述**：

```
书影温故是一个只属于你自己的阅读与观影记录本。

【阅读记录】
· 一本书的每一轮阅读都单独记录：开始时间、结束时间、读到第几页、读完用了多久
· 四种状态自动推导：想读 / 在读 / 再读 / 已读 N 次
· 重读不再覆盖历史，第几次读完一目了然
· 进度环实时显示当前读到百分之多少

【观影记录】
· 想看 / 已看 N 次，记录每次观看的时间与星级
· 补记往期：忘了记录也能补上

【统计概览】
· 累计阅读时长、累计页数、读完本数
· 近 7 天阅读 / 观影趋势
· 最近动态时间线

【关于隐私】
· 数据全部保存在本机，不上传服务器
· 不申请网络权限，不接入统计 / 广告 / 推送等第三方 SDK
· 可随时在设置中清空全部数据或撤回隐私同意

【其他】
· 支持浅色 / 深色主题，跟随系统
· 无广告、无内购、无需注册登录
```

**隐私政策 URL**：`https://leihaocs.github.io/shuying/privacy.html`

**App Privacy（隐私详情）填写**：

| 项 | 选择 |
|---|---|
| 数据类型 | 全部不收集（No data collected） |
| Tracking | 不用于追踪 |
| 权限说明 | 无需填写（App 不申请任何权限） |

**年龄分级问卷**（如实勾选，预期结论 4+）：
暴力/血腥：无；色情：无；赌博：无；烟酒毒品：无；用户生成内容：无；广告：无。

**截图要求**：6.9 英寸（1290×2796）至少 1 组，另建议 6.5 英寸；iPad 若支持需 13 英寸。
无 iPad 支持时，可在 App Store Connect 中声明仅 iPhone。

## 五、托管隐私政策页

`privacy.html` 需要能被公网访问，商店审核会点开验证。三种方式任选：

1. **GitHub Pages**：把 `privacy.html` 推到仓库根或 `docs/`，开启 Pages，
   得到 `https://<用户名>.github.io/<仓库>/privacy.html`
2. **Gitee Pages**：国内访问更快，适合作为国内市场的隐私链接
3. 自己的域名：`scp privacy.html user@server:/var/www/html/`

拿到 URL 后填进三端商店后台，并把 `store/上架素材.md` 里的 `<你的域名>` 替换掉。
