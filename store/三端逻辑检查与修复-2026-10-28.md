## 发现与处理

| 问题 | 处理 | 适用范围 |
|---|---|---|
| 设置、备份、隐私政策的自定义标题没有避开系统状态栏 | 页面主体加 SafeArea，覆盖顶部、侧边和底部；统一明暗主题系统栏文字对比 | 三端 |
| 日期确定后强制再选时间，取消时间导致日期也没选成 | 日期与时间分开；日期确定直接返回，只有点击“添加时间”才显示 24 小时滚轮，取消不修改原值 | 三端的阅读、观影记录 |
| 原日期组件未配置中文本地化 | 使用 Flutter SDK 自带中文 Material/Cupertino 本地化 | 三端 |
| 补记同一天可能因初始时分不同被当成倒置日期 | 初始起止日期统一到中午，范围验证只比较年月日 | 三端 |
| 空阅读记录可以保存；有总页数时仍默认写入未变的手动进度 | 拒绝未填写任何内容且进度未变的记录；有总页数时默认使用页数估算，仍可主动启用手动进度 | 三端 |
| 多条记录的时间相同，最近进度/评分可能取到先添加的那条 | 时间相同时以最后添加的记录优先；开始新一轮也纳入书籍最近阅读时间 | 三端 |
| “清空所有数据”只清内存主列表，旧偏好与上一份备份可能保留真实记录，且先提示成功后写盘 | 清理旧偏好和历史副本，旧偏好先覆写为空以兼容原生异步删除，等待保存成功后再提示；失败保留重试状态 | 三端 |
| 复制备份后异步返回时页面可能已退出 | 使用 mounted 检查再显示提示 | 三端 |
| 商店查询无回调可能一直忙碌；iOS 离线首次查询失败后无恢复入口 | 状态和商品查询增加超时；iOS 保留恢复入口，其余渠道继续由原生能力决定，购买仍由商店验证 | 三端购买公共逻辑 / iOS |
| 窄屏、大字体时列表状态、记录日期、小标题、按钮和年度 12 个月数据行发生水平溢出 | 状态/日期/年度数据采用可换行布局，标题与按钮文字允许受约束布局；隐私标题、设置值、表单标签一并适配 | 三端 |
| 设置页未注入版本时仍显示硬编码旧版本 `(1)` | 正式脚本继续注入真实版本；开发时缺少注入明确显示开发版本 | 三端 |
| 三端脚本在 iOS 使用 exec，导致后面的鸿蒙不执行，且 auto 可能直接上传 | iOS 改为本地 App Store 类型 IPA 导出，完成后继续后续平台；独立 iOS 脚本的 auto 默认也只导出，显式 app-store 模式才上传 | 本机发布流程 |
| Android 缺少发布密钥时静默改用 debug 签名 | release 必须使用发布签名，材料缺失时构建失败 | Android |
| iOS 成品检查提示启动图仍为 Flutter 默认占位素材 | 移除模板图片，改为与 Flutter 加载页一致的原生书本/应用名，支持浅深背景；重新归档后占位警告消失 | iOS |

上一轮鸿蒙输入法删除补丁、phone 设备声明、鸿蒙及国内安卓首启空库和未开放 Pro 入口处理继续保留；用户最新指定 iOS / Google Play 首启保留样例，已按发行渠道分流。

## 手动复测重点

1. 三端新包查看设置、隐私、备份、书籍/电影详情及各弹窗的顶部与底部，确认标题不遮挡状态栏。
2. 阅读与观影仅选日期直接保存；主动添加时间时为滚轮，取消不改变日期/时间，确认后保存并重启核对。
3. 输入中文、数字和表情后退格，尤其 HarmonyOS 6.1 / API 24；覆盖安装前先导出真实数据，确认升级后记录保留。
4. 在测试数据环境验证新增、补记同一天、相同时间的多条记录、导入去重及清空后重启。不要卸载或清空真实用户记录来做首启测试。
5. iOS / Play 使用各自测试商店验证商品、取消、待支付、成功、恢复和退款；Android direct 和鸿蒙不应出现可购买按钮。
