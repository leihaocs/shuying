## 7. 上传构建 → TestFlight 内部测试

```bash
./tool/ios_ipa.sh testflight
```

1. Transporter（Mac App Store 免费）→ 登录同一 Apple ID → 拖入 IPA → 交付
2. 等状态变成「处理完成」（通常 5–30 分钟）
3. TestFlight → 内部测试 → 新建测试组（如「自测」）→ 添加自己 → 勾选该构建
4. iPhone 13 装 TestFlight App → 同一 Apple ID 登录 → 安装

内部测试免审核，构建处理完即可装。单账号最多 100 名内部测试员，构建 90 天后过期。
