## 一句话结论

- **应用宝：个人主体可行，流程能走通，但版权证明是硬门槛**。按你 2026-11-02 的决策（OPPO 暂挂起等软著下证，见 `store/OPPO上架进度记录-2026-11-02.md`），应用宝同样**等软著下证后启动**（常规 30–60 个工作日，预计年底前后）；不想等可以花 100–300 元办电子版权认证提前（OPPO/应用宝/360/阿里通用一张证）。
- **荣耀：个人主体被官方硬性挡住**（审核规范原文"暂不接受个人开发者上传应用"），必须等公司主体。你在筹办的深圳公司落地后即可解锁，与 Apple Developer 主体方案一举两得。
- 想先见用户量的话：**酷安、阿里应用分发**个人可上、不强制软著，素材与 OPPO/vivo 现成可复用。

## 二、应用宝上架流程（个人开发者，可行）

### 前提判断

| 条件 | 本项目状态 |
|---|---|
| 个人账号可注册 | ✅ 支持，但管控严 |
| 版权证明 | **硬必填**（OPPO 2026-11-02 实测同类栏位为前端硬校验，不上传无法提审）。第三方资料称免费工具类可用区块链电子版权；按 11-02 决策：等软著下证（0 元全渠道通用），或花 100–300 元办电子版权提前 |
| APP 备案 | ✅ 已完成（粤ICP备2026143055号-2A） |
| 隐私政策 | `https://bookmovie-revisit.cn/privacy.html`；提交前确认可直接打开且与 App 内正文一致 |
| 帮助与支持 | `https://bookmovie-revisit.cn/support.html`；提交前核对实际上传包的跳转与复制地址 |

### 第一步：注册账号（腾讯开放平台，入口 wikifeishu 以后台为准，用 QQ 号登录）

个人账号材料：

| 材料 | 要求 |
|---|---|
| 独立 QQ 号 | 无违规记录，**长期常用，绑定后不可更换** |
| 身份证正反面 | 清晰原图，本人二代证 |
| 手持身份证照片 | 人脸与证件完整清晰 |
| 人脸核验 + 本人银行卡 | 小额打款核验实名 |
| 手机号 + 邮箱 | 接收审核通知 |

个人账号审核约 1–3 个工作日。注意：**个人账号在商店展示的主体为个人姓名**；不涉及 D-U-N-S 编码（那是苹果/谷歌企业号的事）。

### 第二步：创建应用 + 填写资料

- 应用名称：**书影温故**（与版权证书软件名一字不差）
- 图标：512×512 直角 PNG（`brand/app_icon_512.png` 已有）
- 截图：4–5 张 1080×1920（`brand/vivo-screenshots-20261101/` 竖屏截图可复用，需确认无其他商店品牌标识）
- 分类：工具/效率类；简介避免"最""第一"等绝对化用语
- 隐私政策网址：`https://bookmovie-revisit.cn/privacy.html`，与 APP 内隐私弹窗文本一致；支持网址：`https://bookmovie-revisit.cn/support.html`

### 第三步：资质上传

- 版权证明：**双页电子版权认证证书 PDF**（OPPO 那张同一份复用）
- APP 备案号（已完成，主体须与账号主体一致）
- 软著名称与应用名一致（后缀"APP/软件/平台/系统"可忽略）

### 第四步：上传安装包 + 提审

- 32/64 位兼容 **release 签名 APK（direct flavor，1.0.0(7)）**，包名 `com.bookmovie.revisit.app`
- 上传后机检（病毒/恶意代码/权限扫描）+ 人审，约 1–5 个工作日
- 常见驳回：描述夸大、隐私政策不完整、敏感权限、截图带其他商店 LOGO

## 三、荣耀上架流程（当前被主体阻塞，先挂起）

### 硬性阻塞（官方原文）

《荣耀应用市场审核规范》（developer.honor.com，guides/100879）第 6 条：

> 暂不接受个人开发者上传应用，如需上传应用请注册为企事业单位开发者类型，并提供相关资质文件。

10-31 计划中的判断仍然成立：**荣耀在 P2，受主体条件阻塞**。解除条件 = 深圳公司注册完成 → 以企业主体注册荣耀开发者。另外荣耀 2026-10-29 上线了"开发者身份验证服务"，企业认证流程可能有新变化，届时按当时后台要求走。

### 公司主体落地后的流程（预存备用）

1. **注册账号**：荣耀开发者服务平台（developer.hihonor.com）→ 企业认证（营业执照、法人身份证、对公信息）。
2. **创建应用**：管理中心 > 生态服务 > 应用服务 > 应用分发卡片 → 创建应用，填基本信息：
   - 名称（与安装后桌面显示一致、不与已有应用重名、不用广义归纳词）
   - 图标 320×320、≤200KB
   - 截图至少 3 张（英文规范列 1248×702、每张 ≤2MB；实际上传以后台校验为准）
3. **版本信息页**（发布应用，guides/100884）：
   - 发布国家/地区勾选中国大陆
   - 软件包管理 → 上传 release APK（包名自动读取 `com.bookmovie.revisit.app`）
   - **联运情况选"非联运"**（应用内付费但非联运合作也选非联运；错选联运会无法过审）
   - 内容分级：按年龄段设置
   - 隐私声明：后续填写 `https://bookmovie-revisit.cn/privacy.html`，须能直接打开且与 APP 内一致；支持网址填写 `https://bookmovie-revisit.cn/support.html`
4. **版权信息**（版本信息 > 版权信息）：《计算机软件著作权登记证书》/《软件著作权认证证书》/《APP 电子版权认证证书》**三选一**上传——电子版权那张同样能用；**应用名必须与证书软件名一致**。
5. 机审 + 人审，通过后上架。

### 与既有计划的衔接

- 荣耀素材（320×320 图标、1248×702 截图）**先不制作**，等公司主体明确后再按当时规范生成，避免返工。
- 应用宝 / vivo / OPPO 不受影响，按 10-31 计划 P1 推进；电子版权证书一张三家复用（OPPO / vivo / 应用宝）。
