## 用户确定的免费与 Pro 边界

| 范围 | 当前源码行为 |
|---|---|
| 免费核心 | 不限量书影记录、重读重看、基础统计与主题、搜索、标签/评分筛选、月度回顾、基础卡片、原始 JSON 备份与合并 |
| Pro 买断 | 任意日期范围回顾、年度与跨年对比、重读/重看对照的完整查看、文字复制、完整 PNG/PDF 报告 |
| 国内安卓、鸿蒙 | 用户明确选择“提供高级功能预览，暂不开放购买”；设置中有预览入口，完整选择与导出仍需真实权益 |
| iOS、Google Play | 保持现有商品、价格和购买开关。已有永久权益继续有效；未配置 Play 公钥时不得购买或通过缓存解锁 |

没有新增广告、订阅、多档会员、云账号、AI 或社交后端。报告列出的扫码、第三方书影资料、封面、计时器和小组件属于竞品能力对照，并非本报告优先实施项；本次没有凭空增加数据供应商、内容抓取或持续服务成本。

## 逐项实现

### 数据与业务规则

| 建议 | 实现与边界 |
|---|---|
| 本机大库写得出、读不回 | 沿用 11 月 6 日修复：本机读取与外部导入的大小保护分开。合法本机记录不再受外部 20 MiB 上限阻断 |
| 大备份体验 | 外部文件及粘贴导入默认保留 20 MiB 保护；只有明确确认后允许大文件。超长文本仅缩短页面预览，文件和复制仍保留完整内容，不截断备份 |
| 备份合并冲突 | 保留进度、唯一在读轮次、累计校正等约束；冲突原子拒绝。页面逐书展示来源选择，默认保留本机；采用备份时替换该书整份记录，明确提醒先备份，不宣称双向无损同步 |
| 读取失败恢复 | 启动失败且有上一份副本时提供确认恢复；先验证副本，再留存损坏原件并原子替换。不会静默回滚或删除原件；副本可能不含最近修改 |
| 总页数与历史日期 | 沿用已修复规则：修改总页数也校验自动进度单调性；历史起止日期须包含已有明细；累计校正不充当单次记录，不重复计入统计 |
| 标签与兼容备份 | 书籍、电影均可编辑标签、搜索标签；去空白并忽略大小写去重。新导出 schema 3，兼容导入 schema 1/2/3；旧版不能读取 schema 3。原始备份继续免费，不包含 Pro 权益 |

本机恢复留下的损坏副本可能含私人书影记录，只保存在应用私有目录；用户清空全部记录时一并清理应用管理的恢复副本。

### 日常使用与成果展示

| 建议 | 实现与边界 |
|---|---|
| 搜索和基础筛选 | 书架、电影的全文搜索与状态、标签、评分筛选组合生效；未评分可单独筛选；电影按最新一次观影评分筛选，不拿旧评分冒充最新 |
| 免费月度回顾 | 统计中可选择月份，查看真实汇总、复制基础文字、保存 PNG 或主动调用系统分享；保留自然分享出口 |
| 任选时间范围 | Pro 可选含首尾日的任意日期；校正累计按轮次结束或最近记录日归属，不与日志再次累加 |
| 跨年对比 | 对比两年涉及书影数、阅读次数、页数、分钟、天数、观影次数及已评分观影均分 |
| 重读与重看对照 | 从详情及深度回顾进入；书籍按轮次看起止日期、累计量和感想，只有在读轮次展示进度；电影每次展示实际日期、评分、感想。全书评分不伪造为某轮历史评分 |
| 可看懂的预览 | 有记录时使用真实数据；空库年度示例明确标记且不写入本机库。深度预览限制日期与完整对照，不能导出完整报告；国内没有购买按钮 |
| 完整报告 | Pro 可复制文字、选择暖纸/夜色 PNG，或导出分页 A4 PDF；导出时再次校验权益，文件保存互斥，取消不会修改记录。长图片提示改用 PDF，不悄悄截掉正文 |
| 三端原生文件能力 | Android、iOS、鸿蒙接入 PNG/PDF 系统文件保存及基础 PNG 系统分享；备份 JSON 接口继续保留。导出采用安全文件名、MIME 与文件头校验 |

PDF 使用本机绘制的中文页面图像封装，不是可检索或可选中文字的排版 PDF；文字版另有复制入口。报告有超过 100 页的保护，过长时提示缩短范围或使用完整 JSON。生成文件保留在用户选择的位置；系统分享只在用户主动操作后把内容交给所选应用。

### 购买、隐私和渠道资料

| 建议 | 实现与边界 |
|---|---|
| 支付异常等待 | 沿用购买/恢复/查询超时与迟到回调处理；UI 超时不当作已付款失败；撤回隐私同意后不自动查询商店 |
| Play 永久买断离线 | 仅缓存 RSA 验证、包名/SKU 匹配、已购买且已确认的完整凭证；AndroidKeyStore + AES-GCM、私有非备份文件存储。只在临时查询失败时兜底，购买与恢复仍走真实商店 |
| 退款/账号切换 | 成功商店查询结果优先并能清除过期权益；离线期间无法实时得知退款或账号切换，不宣传跨账号、跨平台永久离线授权，不用本地布尔值或 JSON 解锁 |
| iOS 权益 | 保留 StoreKit 2 验证权益和撤销检查，不引入另一套本地布尔授权。真实付款、恢复、退款仍待账号实测 |
| 中文语言声明 | iOS 工程开发区域及本地化声明改为简体中文，随下次包提交；不声称当前 App Store 语言已变更 |
| 使用说明与提审文案 | 更新使用说明；提供下一版渠道文案及验收表，不把未开放购买、未上线包或预览当成已售能力 |
| 商业验证 | 提供按周记录商店展示、下载、购买、退款、收入和自愿反馈的模板。不增加埋点 SDK，不把零评分当作零下载，不伪造活跃率或收入 |

离线权益细节：[Play 买断离线缓存与验收](Play买断离线缓存与验收-2026-11-07.md)。
