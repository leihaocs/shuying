## 工程改动

- 原生本地 `supportUrl` 配置：安卓只有 `BuildConfig.FLAVOR == play` 返回 GitHub，其他安卓渠道默认自有域名；鸿蒙返回自有域名，iOS 保持 GitHub。
- Flutter 支持页读取一次配置，展示、复制和打开使用同一地址；不通过首启样例策略推断渠道。
- 原生无参 `openSupport` 继续沿用本渠道默认地址，兼容旧调用；有参仅接受精确的当前渠道 HTTPS 支持页。
- 配置不可用时保留离线帮助和邮箱；旧原生桥接未实现配置方法时保持原 GitHub 行为。
- 这部分是源码更新，不会自动改变已经编译/安装的包。本轮未重新出任何平台安装包，版本号保持原约定。

前一阶段（鸿蒙仍为 GitHub 时）的定向测试 10 项、完整 Flutter 回归 122 项及静态分析已通过，历史日志归档于 `dist/website/20261106-aliyun/`。本轮最终规则已同步修改鸿蒙配置和测试期望，并核对 iOS / Play 仍为 GitHub；按用户不编译的要求，不重新运行需要编译的 Flutter 测试或任何安装包构建。
