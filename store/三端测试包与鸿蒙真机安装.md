# 书影温故 1.0.0 (2) 测试包

本目录保存同一轮三端候选构建。安装前先从旧 App 导出 JSON 备份。优先覆盖安装，不要先卸载。

## iOS

`shuying-ios-1.0.0-2.ipa`：Apple Distribution / App Store 导出签名。

打开 Mac 的 Transporter，登录现有开发者账号，添加 IPA 并上传；App Store Connect → App → TestFlight → 等待处理 → 选择测试组。随后在 iPhone 上用 TestFlight 更新到 1.0.0 (2)。该 IPA 不能直接点开安装。

## Android

`shuying-android-1.0.0-2.apk`：Android 安装测试使用；允许文件来源安装后打开 APK，或执行 `adb install -r <APK路径>`。使用现有 release 密钥签名，旧版如签名不同会提示更新不兼容，先备份并核对，勿直接卸载。

Google Play 使用同版本 `.aab`，不能把 AAB 当 APK 安装。Pro 商品及 Play 公钥未配置时购买不可用；本包可验收免费记录、备份与合并功能。

## 鸿蒙（重要）

`shuying-ohos-1.0.0-2.hap`：API 15 / arm64 / OpenHarmony 工程的本地调试签名。已编译通过，不代表已适配你的华为零售手机签名。

当前 profile 的 developer-id 为 OpenHarmony、device-ids 为空；电脑尚未检测到鸿蒙设备。华为真机可能拒绝这个自签名包，不能靠改文件后缀解决，也不要关闭设备安全校验。

1. 用户已确认设备为华为 Mate 80、HarmonyOS 7；完整系统构建号尚待通过手机或 hdc 核对。当前 HAP 仍为 OpenHarmony API 15 构建，尚未在此设备验证兼容性。
2. 用 USB 连接 Mac。手机开启开发者模式及 USB 调试，确认电脑连接授权。
3. DevEco Studio 打开 `flutter_app/ohos`，登录华为开发者账号。Project Structure → Signing Configs → 对应 product → Support HarmonyOS / Automatically generate signature，选择已连接的手机，生成包含该设备的正式调试证书及 Profile。
4. 保存匹配 bundleName `com.bookmovie.revisit.app` 的签名配置，重新构建 HAP。不要对外发送 p12 私钥和密码。
5. 核对 `hdc list targets` 后执行 `hdc install -r <正式真机签名HAP路径>`，打开书影温故。如有失败，保留完整错误；不要卸载旧数据或尝试绕过验签。

本机 hdc 位于 `/Users/leihao/openharmony/sdk/15/openharmony/15/toolchains/hdc`。

签名参考：[华为调试 Profile 文档](https://developer.huawei.com/consumer/cn/doc/doccenter-getting-started/agc-help-debug-profile-0000002248181278)。

## 必测项

1. 旧版覆盖升级后，书籍/电影和全部记录保留，设置页版本显示 1.0.0 (2)。
2. 新增阅读/观影记录，观察保存完成；立即切后台、强制结束、重开核对。
3. 端 A 导出 JSON → 端 B 合并导入 → B 新增 → 导回 A。连续导入两次，无重复、不删已有条目。
4. 导入损坏 JSON 必须拒绝且保留原记录；空备份不清空。
5. Pro 示例明确为示例；真实购买需商店商品配置后单独验收，不以 JSON 转移会员。

## Mate 80 / HarmonyOS 7 专项进度

用户已提供目标设备信息。官方 HarmonyOS 7 对应 API 26，建议评估升级至对应开发套件；本机当前只有 OpenHarmony API 15，不能直接把版本数字改成 26 后宣称完成适配。先评估对应官方 SDK 的升级与 Flutter 引擎兼容性，配置华为真机调试证书/Profile，并通过设备安装与运行验证。官方建议升级开发套件不等于旧 API 15 包一定不能运行；现阶段尚未验证。当前 hdc 尚无连接设备，未发现本机华为官方调试证书。

参考：[华为官方升级适配指南](https://developer.huawei.com/consumer/en/doc/harmonyos-releases/upgrade-adaptation)。

## 鸿蒙版本支持决策（2026-10-02）

- 发布最低支持：HarmonyOS 6.0（API 20）；重点支持和真机验收：HarmonyOS 7，用户设备为 Mate 80。
- HarmonyOS 5 不纳入首发支持承诺和必测矩阵，不为其增加额外兼容分支。当前记录、文件选择器和统计代码没有证据显示支持 5 必然引发问题；主要成本是旧版 Flutter/依赖兼容和增加设备回归测试。排除 5 是控制首发范围，不是断言该系统有问题。
- 使用一份 HAP 覆盖 6 和 7，不为两个系统维护不同 JSON 协议或业务代码。
- 正式开发套件升级评估目标为 HarmonyOS 7 对应 API 26，最低兼容字段为 `6.0.0(20)`。须根据新工具的实际格式配置 compile/target SDK 并验证 Flutter 引擎及插件，禁止仅改数字宣称适配完成。
- 当前已有 HAP 仍是 OpenHarmony API 15 的编译与本地签名产物，不作为“最低 6、已适配 6/7”的正式包。尚未升级官方 SDK，也没有完成华为真机签名。
- 验收必须同时包含：Mate 80 / HarmonyOS 7 真机，以及 HarmonyOS 6 的真实设备或可信远程设备测试。模拟器仅补充布局检查，不能替代真机文件选择、保存和安装验签。
- 两个系统均测试：覆盖升级数据迁移、立即退出保存、JSON 文件双向合并、系统文件选择器、主题/统计；Pro 支付另依赖华为 IAP 接入与商品配置。

参考：[华为官方升级适配指南](https://developer.huawei.com/consumer/en/doc/harmonyos-releases/upgrade-adaptation)，[HarmonyOS 6 API 20 官方变更说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/apidiff-6002)。
