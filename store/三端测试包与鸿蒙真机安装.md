## 无线调试与安装

1. 手机和电脑处于可互通的局域网，手机打开无线调试，保持解锁亮屏；端口以手机当前显示为准，关闭再开可能变化。Wi-Fi 6/6+ 标识差异无需调整。
2. 在 DevEco 的 IP 连接入口输入手机当前 `IP:端口`，允许手机调试授权；也可用以下 hdc 命令。
3. 本地 `build-profile.json5` 已保留 `default` 发布配置与 `debug` 自动调试配置。调试构建应选择 `debug` 签名，完成后恢复默认发布选择；不要用发布 Profile 替代调试设备授权。
4. 安装调试 HAP，启动 `.hm` 应用；商店上传用发布 `.app`，不混用。

在仓库根目录执行，替换当前连接地址：

```bash
HDC=/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc
"$HDC" tconn <手机IP:端口>
"$HDC" list targets
"$HDC" -t <手机IP:端口> install -r dist/1.0.0-2/shuying-harmonyos-hm-debug-1.0.0-2.hap
"$HDC" -t <手机IP:端口> shell aa start -a EntryAbility -b com.bookmovie.revisit.app.hm
```

2026-10-17 已得到 `install bundle successfully` 和 `start ability successfully`，随后用户确认功能验证通过。该结论针对 Mate80 / HarmonyOS 7，不推定其他系统、平板或真实支付通过。
