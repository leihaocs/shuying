# 阿里云官网首页

`index.html` 是 `https://bookmovie-revisit.cn/` 的独立静态首页，来自 2026-11-08 的服务器原文件，补充真实公安备案页脚。项目根目录的 `index.html` 是 Vite 入口，两者用途不同。

- 网站 ICP：粤ICP备2026143055号-3。
- 公安备案：粤公网安备44030002019153号，号码及查询 HTML 由用户提供。
- `beian.png`：[公安平台“备案编号图标”原图](https://beian.mps.gov.cn/static/national%20emblem.png)，20×20 PNG，未修改。
- 发布脚本：`tool/publish_homepage_filing.sh`，仅更新 `/data/www/index.html` 和 `/data/www/beian.png`。
- 备份、校验及实际发布状态：[部署记录](../../store/官网公安备案标识核对与部署-2026-11-08.md)。
